# 微信交付要求

本Skill以微信表情专辑为交付目标，暂不扩展其它平台配置。当前基线综合用户2026-10-27的表情主图概览与2026-11-04提供的五张规范截图；后者补充名称、介绍、横幅、封面、聊天页图标要求，覆盖旧版冲突内容。它是用户指定的制作依据，不冒称已实时核实官方所有规则。

## 名称与介绍

- 专辑名称：不超过8个汉字，不包含任何标点；5个汉字以内显示效果最佳，中文名称避免空格，避免与已有专辑重名。
- 专辑介绍：不超过80个汉字，实际描述角色特点或故事情节，不只写“这是我的表情包”。
- 校验器保守按Unicode字符数计长度，中文、英文、数字、空格和标点均计入，不仅计算汉字；这不是对微信混合字符计数算法的推断。名称>8或含Unicode标点、ASCII标点及其全角兼容形式为错误，>5或有空白给提示；介绍必填且≤80。介绍可以含标点。
- 重名须在可访问的微信专辑信息中核对，记录范围与结果；不能仅凭通用搜索无结果保证全平台唯一。无法核对时明确名称尚未完成查重，不虚构结论。

## 文件与画面

| 素材 | 数量 | 格式 | 尺寸 | 本Skill导出预算 |
|---|---:|---|---|---:|
| 表情主图 | 8～24 | 静态PNG/JPG/GIF，动态GIF | 240×240 | ≤500KB |
| 详情页横幅 | 1 | JPG/PNG | 750×400 | ≤500KB |
| 专辑封面 | 1 | PNG | 240×240 | ≤500KB |
| 聊天页图标 | 1 | PNG | 50×50 | ≤100KB |

本次截图称横幅/封面超过500KB、图标超过100KB“将被压缩”，不是“禁止上传”。本Skill继续以该值作为保守导出预算，避免平台再压缩影响画质；脚本超预算不通过，不代表宣称微信一定拒绝上传。KB按1000字节计，是本工具的保守约定。主图数量/尺寸等沿用前次截图，本次没有新增主图背景或描边要求，不把封面规定直接套给所有主图。

### 详情页横幅

在专辑详情页顶部展示。默认无任何文字信息，采用活泼明朗的色调、与微信底色有明显区分的非白色背景，避免透明背景。画面应与本套角色/表达有关、有情境或故事，内容丰富；完整构图，不拉伸或压扁角色。不要把专辑名称和介绍画进横幅。

### 专辑封面

选最有辨识度的角色正面半身或全身形象，避免只用头部。必须透明背景，避免白底；角色不加白色描边，检查锯齿。布局紧凑、留白适量、画面简洁，避免装饰元素；除纯文字类表情外避免出现文字。与其它专辑区分，不能复用同一封面。

### 聊天页图标

选清晰、最有辨识度的角色正面头部，按50px单独构图，不用复杂横幅直接缩小。必须透明背景，避免白底；角色不加白色描边，检查锯齿，不出现正方形边框或生硬直角主体边缘。画面简洁、无多余装饰、留白适量，与其它专辑的图标不同。

这些规则区分白色角色填充与白色外描边/背景：白色身体可以保留，不能把身体也抠成透明。横幅不宜透明，而封面和图标须透明，不能共用一种背景处理。

## 程序检查与独立视觉检查

程序检查实际编码、尺寸、体积、数量、路径、名称/介绍，以及封面/图标是否存在全透明像素。存在透明像素并不能证明背景处理正确；纯白底挖一个透明点、棋盘格假透明、白描边、文字、正面/半身构图、留白、故事性、变形与跨专辑重复，仍须实际视觉评审，不用简单阈值或未执行的OCR冒充检查。

最终独立评审需按素材用途逐项确认：banner_design（无字、背景、情境、无拉伸）、cover_design（正面半身/全身、透明、无白描边、文字例外与简洁构图）、icon_design（正面头部、透明、无白描边、50px清晰、无方框）。报告须写platform_evidence，记录观察依据及未核对的跨专辑重复/名称查重范围。详情见 [独立评审](review.md) 和 [报告格式](review-report.md)。

## 清单与版本迁移

当前profile为`wechat-user-2026-11-04`。manifest必含名称与介绍，介绍保存在JSON中作为微信上传文案，不能自动画进横幅。示例只演示字段，正式stickers需列全8～24张：

```json
{
  "profile": "wechat-user-2026-11-04",
  "name": "慢半拍",
  "name_status": "confirmed",
  "description": "一只慢半拍的小伙伴，用懒懒的表情回应生活里的大小事。",
  "mode": "animated",
  "count": 8,
  "stickers": [
    {"file": "stickers/收到.gif", "meaning": "收到", "text": "收到"}
  ],
  "banner": "banner.png",
  "cover": "cover.png",
  "icon": "icon.png"
}
```

name_status为confirmed或provisional，mode为static或animated。路径相对manifest，不可越出delivery或重复引用；动态至少两帧且无限循环。表情文件按含义命名，不使用纯编号或默认编号前缀；去掉跨平台不适用的`/ \\ : * ? " < > |`字符，同名用语气或动作后缀区分。文件名是文件命名规则，不受专辑名称8字/无标点规则约束；配字可含标点。

旧profile不自动升级为通过：旧清单需补介绍、检查配套图及文案，再更新profile并重新校验和评审。清单/文件改变会使旧哈希评审失效；不静默修改已有案例或把历史通过结果当成新标准通过。

```bash
python3 <skill目录>/scripts/validate_pack.py <项目>/delivery/manifest.json --report <项目>/validation.json
```

报告写新路径；退出码0仅表示可机械检查项通过，1为失败，参数错误为2。名称暂定、查重、视觉项等仍需如实说明。

正式合格ZIP仅使用 [受检打包工具](review-report.md)，只包含manifest及清单内最终素材，不带源图、个人资料或过程评审记录；未过项本地返修，不补入合格清单。

官方入口：[微信表情开放平台](https://sticker.weixin.qq.com/)、[制作指引](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/makingSpecifications#specifications_stickers)。正式投稿前尝试核对当前规则；页面不可读时沿用本次用户基线并说明，Skill不自动投稿。
