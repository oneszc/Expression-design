# 静态表情制作

按项目已确认的角色参考、表达清单和画风制作。不要把人物照片输入当成所有项目的起点。

## 样张

多方向阶段使用相同聊天含义比较设计；角色已定后，选择能覆盖平静、夸张和大幅动作的少量表达测试。观察轮廓、面部特征和标志配饰在不同姿态下是否仍然成立。

提示词组织为“参考图角色 + 本张聊天含义 + 动作与神态 + 固定特征 + 背景与画幅”。优先简短、具体，不堆叠无关禁令。例如在角色已确认的项目中：

```text
沿用参考图的角色、比例、配色和线条，画一张表达“收到”的表情。
角色认真点头并抬手示意，神态符合已有性格。
动作完整，四周留少量边距，透明背景，不添加文字。
```

用户需要配字时使用已经规划的原文。字形、断句和位置要在最终尺寸逐字检查；必要时后期排字，保留无字原图。

## 导出

- 默认透明 PNG；不是要求所有项目改为透明风格，已有明确背景按用户意图保留。
- 按主体外接范围等比缩放到 240×240 画布，保留手脚、配饰和动作延伸空间，不拉伸成正方形。
- 不能把白底或画出来的棋盘格当作透明。用浅、深两种底色检查真实 alpha 和轮廓。
- 保留高清源图，压缩后的最终文件重新打开检查。文字或线条糊掉时调整设计与导出参数，不以满足体积为唯一目标。
- 表情封面与面板图标单独构图：50×50 图标要在真实尺寸检查，不用缩放后的大图替代。
